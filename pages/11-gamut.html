11 — Color gamuts

A gamut is the set of colors a device can produce (a screen) or reproduce (a printer). Some colors are simply out-of-gamut.

Big idea: Out-of-gamut colors must be mapped (clipped/compressed) when converting between devices — that’s why the same “color” can change when printed.

Not every crayon fits in the box

  • Some screens can show very bright colors.
  • Some printers can’t print those exact colors.
  • When a color is missing, we pick the closest one we can.

Gamut depends on primaries + medium

  • Displays: primaries define a triangle-like region (in chromaticity).
  • Printers: ink set + paper define a different region (often smaller in some areas).
  • Color management chooses how to map out-of-gamut colors (rendering intents).

Chromaticity and volume
