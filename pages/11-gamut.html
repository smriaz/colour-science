11 — Color gamuts

A gamut is the set of colors a device can produce (a screen) or reproduce (a printer). Some colors are simply out-of-gamut.

Big idea: Out-of-gamut colors must be mapped (clipped/compressed) when converting between devices — that’s why the same “color” can change when printed.

Not every crayon fits in the box

  • Some screens can show very bright colors.
  • Some printers can’t print those exact colors.
  • When a color is missing, we pick the closest one we can.

Gamut depends on primaries + medium

  • Displays: primaries and backlight define a triangle-like region (in chromaticity).
  • Printers: ink set + paper define a different region (often lumpy and smaller in some areas).
  • Color management chooses how to map out-of-gamut colors (rendering intents).

Chromaticity and volume

Gamuts are 3D volumes (e.g., in Lab), not just 2D shapes. Here we’ll show a toy 2D view (xy-ish) to build intuition. Real printer gamuts are irregular and depend on tone, black generation, and media.

What clipping means

  • If your chosen point is inside the printer polygon, it stays the same.
  • If it’s outside, we move it to the nearest point on the polygon edge.
  • This often reduces saturation (colors look “duller” when printed).

What you learned

Short recap.

  • A gamut is the set of colors a device can produce/reproduce.
  • Out-of-gamut colors must be mapped when converting between devices.
  • Clipping is one mapping; real workflows often use perceptual compression + profiles.
