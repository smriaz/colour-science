06 — Color picking (Hex, RGB, HSL)

Designers and coders often describe colors with hex (like #FF8800), or with models like RGB and HSL.

Big idea: RGB is great for screens, but HSL is great for humans: hue (color name-ish), saturation (how colorful), lightness (how bright).

Three ways to say a color

  • RGB: how much Red, Green, Blue light
  • Hex: RGB written in a short code
  • HSL: hue + how colorful + how light/dark

Hex is just RGB in base-16

#RRGGBB is three numbers written in hex. For example: #FF0000 = red, #00FF00 = green, #0000FF = blue.

HSL is not perceptually uniform

HSL/HSV are convenient, but equal steps do not correspond to equal perceived differences. Later we’ll use more perceptual spaces (Lab) and proper differences (ΔE).

Still, HSL is useful for UI controls and for talking about “hue” and “lightness” intuitively.

Hue is the “color family” (red → yellow → green → blue → back to red).
0% saturation is gray. Higher is more “colorful.”
Lightness changes how dark/bright it looks.

What you learned

Short recap.

  • #RRGGBB is just RGB written in hexadecimal.
  • HSL is a convenient “human-ish” way to control colors in UIs.
  • Not all spaces are good for all tasks — later we’ll use XYZ/Lab for deeper science.
