14 — Resources

A curated set of books, standards, datasets, and tools for going deeper in vision science and printing.

Tip: Don’t try to read everything. Pick a path, build intuition, then come back for the standards.

Suggested learning paths

Choose what matches your goals.

Path A: Vision science focus

👁️ cones → color appearance 🧠 adaptation 🧪 perception experiments

1) Fundamentals

Trichromacy, cone fundamentals, opponent processing, and basic colorimetry.

2) Color appearance

Context effects, adaptation, and appearance models (intuition first, equations later).

3) Measurement & models

Matching functions, observers, illuminants, and ΔE differences.

Where this path helps
  • Display calibration for perception-critical tasks
  • Research in vision, perception, and HCI
  • Understanding why “same pixels” can look different

Path B: Printing & color management focus

🖨️ CMYK + profiles 📏 ΔE tolerances 💡 viewing conditions

1) Colorimetry essentials

XYZ/Lab, illuminants, measurement geometry, and ΔE.

2) ICC workflows

Profiles, rendering intents, soft proofing, and device link concepts.

3) Press realities

Paper/ink variation, dot gain, standards (ISO), and QA processes.

Where this path helps
  • Brand color consistency across print runs
  • Building reliable proofing workflows
  • Troubleshooting “it matched on screen but not on paper”

Books & references

A small set that covers most of the field.

Good first books

  • Wyszecki & Stiles — classic, comprehensive (heavier).
  • Fairchild — color appearance (great bridge from intuition → models).
  • Hunt — the reproduction problem (printing / imaging perspective).
📚
How to use books: skim chapters aligned with your current lesson (e.g., ΔE, metamerism, gamut), then come back when you have questions.

Printing / color management references

  • ICC profile documentation (concepts: PCS, intents, transforms).
  • ISO standards for print processes and proofing (workflow guidance).
  • Vendor docs (press/paper) for practical constraints and targets.

Practical note: standards are extremely useful — but often easier after you’ve built intuition.

What to read if you only have one weekend
  • One chapter on colorimetry (XYZ, Lab, illuminants)
  • One chapter on color difference (ΔE, tolerances)
  • One chapter on color reproduction (profiles, gamut mapping)

Standards, datasets, and tools

Stuff you can use to measure, test, and build.

Standards (what they’re for)

  • CIE colorimetric observers — standard matching functions.
  • Standard illuminants — D-series, A, etc. for reference viewing.
  • Color difference formulas — ΔE variants (industry tolerances).
  • Viewing conditions — how to set up consistent evaluation.

In printing, standards matter because everyone needs to agree what “match” means.

Datasets & practical files

  • ColorChecker / target charts — practical test references.
  • Measured spectral reflectance sets — for metamerism and illuminant studies.
  • ICC profiles — real device characterization data.

Tip: keep a folder of “known good” test images and profiles for debugging.

Tools (software)

  • Display calibration tools (colorimeter + software).
  • Profile inspection tools (view LUTs, gamut plots).
  • Scientific scripting (Python/Matlab) for conversions & plots.
Suggested “starter kit” setup
  • A decent monitor + consistent room lighting
  • A basic colorimeter (for calibration)
  • A folder of test targets + reference profiles
  • A notebook for recording conditions (illumination, paper, settings)

Tools (printing workflow)

  • Soft proofing in an image editor (simulate paper/profile).
  • Spectrophotometer for measurement (press QA).
  • Viewing booth (standard illuminant conditions for evaluation).
💡
Pro tip: Most “mystery” print color problems are actually viewing condition or profile mismatch problems.
